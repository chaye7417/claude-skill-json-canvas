# JSON Canvas 编辑器 (JSON Canvas)

创建和编辑 Obsidian Canvas 文件（`.canvas`），支持节点、连线、分组等功能。

## 功能

- 创建符合 JSON Canvas 1.0 规范的画布文件
- 支持四种节点类型：文本、文件、链接、分组
- 支持节点间连线和箭头
- 自动计算节点布局
- 兼容 Obsidian Canvas 视图

## 使用方法

在 Claude Code 中说：
- "创建一个 Canvas 文件"
- "画一个流程图画布"
- "用 Canvas 组织这些笔记"

## 节点类型

| 类型 | 说明 |
|------|------|
| text | 文本节点，支持 Markdown |
| file | 链接到库中的文件 |
| link | 嵌入网页 |
| group | 分组容器 |
